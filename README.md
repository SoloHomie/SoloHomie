#### What I Do

I believe software should not just work — it should feel good. Smooth animations, clean interfaces, thoughtful
interactions. Currently pouring that energy into one project:

<p>
  <a href="https://api.solohomie.top"><b>BallsHackPro</b></a> — a desktop assistant for 球球大作战 (Battle of Balls),
built with C++ and Qt 6.
</p>

- Real-time memory scanning and ball tracking
- Low-level keyboard & mouse hook system with silent-uninstall watchdog
- ARM64 inline hook engine for Android emulator detection bypass
- Custom installer with incremental update support
- Dark-mode native UI with acrylic/mica material backgrounds

Every pixel, every animation, every keyboard shortcut — built with the goal of making complex game tooling feel
effortless.
